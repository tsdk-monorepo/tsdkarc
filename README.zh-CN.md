本仓库为 Monorepo 架构，包含以下三个独立发布的工具包，请按需点击查看详细文档：

- **[tsdkarc](./tsdkarc/README.zh-CN.md)**：无装饰器、极简的类型安全依赖注入（DI）与模块组合库。

- **[tsdkarc-x](./tsdkarc-x/README.zh-CN.md)**：基于 `tsdkarc` 的端到端类型安全 RPC 框架，支持路由、中间件及多协议。

- **[tsdkbundle](./tsdkbundle/README.zh-CN.md)**：基于 Bun 的 ESM 多入口开发监测与打包工具。（运行环境：Bun）
