A lightweight, magic-free, and end-to-end type-safe backend development toolchain for TypeScript.

This repository is a Monorepo containing three independently published packages. Click the links below for detailed documentation:

- **[tsdkarc](./tsdkarc/README.md)**: A decorator-free, minimalist, and type-safe Dependency Injection (DI) and module composition library.

- **[tsdkarc-x](./tsdkarc-x/README.md)**: An end-to-end type-safe RPC framework built on top of `tsdkarc`, supporting middlewares and multiple protocols.

- **[tsdkbundle](./tsdkbundle/README.md)**: A Bun-based ESM multi-entry development monitor and bundling tool. (Runtime: Bun)
